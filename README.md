# Vertex CMS — Mobile Web Prototype

High-fidelity, clickable mobile web prototype for CMS mobile UX review (CMS-1465–1469).

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3002/mobile-preview](http://localhost:3002/mobile-preview).

Port **3002** avoids conflicting with the sibling marketing site on 3000.

## Stack

Next.js 14 · React 18 · TypeScript · Tailwind CSS · DM Sans

Brand colors align with the VertexBuild / Vertex CMS marketing design tokens.
